# Pebble tools

- [Pebble Screenshot Tool](pebble-screenshot-tool) — deterministic emulator
  capture, button input, lighting variants, and cross-platform checks.
- [Pebble Watchface Toolkit](pebble-watchface) — project templates, SDK
  references, asset helpers, and validation scripts.
- `pebble-emulator-qa.mjs` — one isolated Emery session with an owner-checked
  lock, native 200x228 captures, a numbered contact sheet, and failure-safe
  restoration of the developer's emulator state.
