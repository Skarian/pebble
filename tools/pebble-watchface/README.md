# Pebble Watchface Toolkit

Templates and helper scripts for taking a Pebble watchface from an idea to a
built PBW with emulator screenshots and visual verification.

![Example watchface produced with the Pebble workflow](../../watchfaces/casio-field-face-c/emulator-current.png)

The toolkit defaults to Pebble Time 2 (`emery`) and includes:

- native C templates for static, animated, and weather-enabled faces;
- drawing, animation, and SDK API references;
- UUID, icon, preview GIF, and project-validation helpers;
- battery-aware guidance for minute updates and short-lived animation.

See [`SKILL.md`](SKILL.md) for the complete end-to-end workflow.
