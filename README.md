# Pebble workspace

Pebble apps, watchfaces, design studies, emulator fixtures, and local QA tools.

## Projects

- `cpap/` — ResMed myAir score watchapp with seven-day details, charts,
  scheduled checks, phone settings, and durable diagnostics.
- `pebble-screenshot-tool/` — deterministic cross-platform emulator capture and
  button-control CLI.
- `emulator-smoke-face/` — small emulator smoke-test app.
- `casio-field-face/`, `casio-field-face-c/`, and `field-terminal/` — Pebble
  watchface projects and experiments.
- `pebble-watchface/` — local Pebble watchface development skill and references.
- `design-studies/`, `heeler-references/`, and `screenshot-variants/` — visual
  references and verified design output.

Each runnable project keeps its own README, package scripts, and build files.
Generated PBWs, build directories, QA runs, caches, and private environment
files are excluded from this repository.
